# Cadastro de Pessoas

Aplicação desktop desenvolvida em Java Swing para cadastrar, visualizar, alterar e excluir pessoas.

## 📋 Funcionalidades

- Cadastrar pessoas (nome, endereço e e-mail)
- Listar pessoas cadastradas
- Navegar entre os registros (◀ ▶)
- Alterar dados de uma pessoa
- Excluir pessoa com confirmação

## 🛠️ Tecnologias

- Java (JDK 25 - Temurin)
- Java Swing
- Apache NetBeans 31
